# **VacuiOS Core**

This repository consists of the source code of the VacuiOS core components, such as
the kernel, boot loader and libraries.
Its documentation is available in [`vacuiteam/docs`](https://github.com/vacuiteam/docs).
Notice that this component is not complete and will be worked on as soon as VacuiOS
and VacuiHW get their documentation.
